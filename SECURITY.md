# Security policy

## Supported versions

| Version | Security fixes |
| --- | --- |
| 0.9.x Open Beta | Yes |
| Earlier internal builds | No |

## Report a vulnerability

Use GitHub's private vulnerability reporting for this repository. Do not open a public issue for a vulnerability that could expose local files, cookies, credentials, downloaded content, or arbitrary command execution.

Include the affected dlME version, Windows version, reproduction steps, impact, and any safe supporting files. Remove cookies, authentication headers, personal paths, and private media URLs.

Ordinary download failures, unsupported websites, and upstream extractor breakage belong in the public bug tracker when they do not expose sensitive information.
