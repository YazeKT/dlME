# Support

Use [GitHub Issues](https://github.com/YazeKT/dlME/issues) for reproducible bugs and feature requests.

For a download problem, include:

- dlME version and Windows version
- yt-dlp version shown in the app
- whether the URL is public or requires an account
- selected format and output type
- the final error category and sanitized log lines
- whether the same URL works after updating yt-dlp

Never publish cookies, browser profiles, passwords, tokens, private URLs, or downloaded media. Website changes can break an extractor without a dlME release. DRM and access-control bypass requests are outside the project scope.
