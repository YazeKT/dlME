dlME User Guide

dlME is a local Windows media downloader by Yaze Media. Download only media you have permission to save.

Download video or audio

  1. Paste a supported URL in Downloader and select Analyze URL.
  2. Choose Video or Audio only. The default is 1080p MP4.
  3. Choose a folder and select Start download.
  4. Wait for the green verified status. dlME checks the final file with FFprobe before completion.

Account-required media

Browser access is optional and off by default. Enable it only for media that genuinely needs an account. dlME stores the selected browser/profile name, never passwords or extracted cookies.

Locked Chromium profile: If Chrome, Edge, or Brave keeps its cookie database locked, dlME retries public media once without browser access. For account-required media, fully exit the browser, including background processes, or use a signed-in Firefox profile.

Recovery

Pause preserves partial files. Retry resumes the same deterministic output and checks your selected browser again. If an item remains blocked, use Export diagnostics and attach the sanitized JSON file to a GitHub issue.

Updates

dlME checks the official stable yt-dlp channel at startup. Updates require your explicit Install action and are verified before activation.
