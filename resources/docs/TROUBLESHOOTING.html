dlME Troubleshooting

Chrome cookie database could not be copied or decrypted

dlME 0.9.1 retries public media once without browser access. For account-required media, fully exit Chrome, Edge, or Brave, including background processes, then select Retry. If the profile remains unavailable, use a signed-in Firefox profile.

Output exists but validation reports ENOENT

dlME recovers the real output by media ID if Windows changes punctuation while decoding the reported path. Retry the item after updating.

YouTube asks you to sign in

First verify the video plays in your browser. Enable a browser session only if the media is age-restricted, private, members-only, or otherwise requires your account. Account use can trigger rate limits.

Website stopped working

Open About and install the available official engine update. If the engine is current, export diagnostics from Downloader or History and contact Yaze Media.

DRM: dlME does not bypass DRM, subscriptions, geo-restrictions, or access controls.
