# Supported sites

dlME obtains its list from `yt-dlp --list-extractors` at runtime. This keeps the Supported page aligned with the installed engine instead of maintaining a short, stale marketing list.

Use search, extractor type, initial-letter, and status filters with pagination. Some extractors represent a platform family rather than one public website.

Listing means that yt-dlp contains an extractor. It does not guarantee every URL or account will work. Common reasons include:

- the website changed after the engine release
- authentication or subscription is required
- regional restrictions
- rate limiting or anti-bot challenges
- DRM or another access control
- removed or private media

Update yt-dlp from Settings before reporting a public URL that has stopped working. dlME will not bypass DRM or access controls.
